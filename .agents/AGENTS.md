## Scope

`.agents/` holds agent skills (`.agents/skills/<name>/SKILL.md`). Root
`AGENTS.md` is canonical — specialize here, never duplicate its sections.
Skill catalog: `agents-docs/AVAILABLE_SKILLS.md` (generated by
`scripts/generate-available-skills.py`; do not hand-edit).

## `.agents/`-specific rules

- **Skill-scoped learnings** → `.agents/skills/<name>/AGENTS.md` (root
  `AGENTS.md` Tier 2 #12); project-wide → `agents-docs/LEARNINGS.md`;
  script → `scripts/AGENTS.md`.
- **Demo-account live e2e recipe** → `plans/256-goap-demo-login-e2e-vertical.md`.
- **Cloudflare deployment & binding preflight** → Pages Functions builds validate
  all declared bindings (D1, KV, R2) at deploy time per official Cloudflare docs
  (`pages/functions/wrangler-configuration/`). Never remove required bindings
  (`BOOKS_BUCKET`, `DB`) to silence deploy failures — `files.ts:41` requires R2
  to serve EPUB bytes and ADR-1014 requires isolated preview R2. Run
  `pnpm preflight:cloudflare` with explicit `CLOUDFLARE_API_TOKEN` and
  `CLOUDFLARE_ACCOUNT_ID`; it checks production and preview resources fail-closed.
  R2 error 10042 ("Please enable R2 through the Cloudflare Dashboard") requires
  account-owner activation before bucket creation. Retrieve deployment logs via
  `/accounts/{id}/pages/projects/{project}/deployments/{id}/history/logs`.
  Skill: `.agents/skills/cloudflare-deployment/SKILL.md`.
